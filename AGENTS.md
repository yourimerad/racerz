# racerz

Jeu web de course 2D (canvas) sur circuit, déployé sur Vercel (projet `solidz/racerz`, prod : https://racerz-jet.vercel.app). **Vérifier une mise en ligne** : l'API GitHub `deployments?sha=<sha de main>` doit montrer une entrée `environment: Production` en `success` pour le commit fusionné — un déploiement `Preview` du même sha (créé par le push de la branche de travail) n'a rien mis en ligne ; si aucune entrée Production n'apparaît en quelques minutes, un nouveau push sur `main` la relance.
